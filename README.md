# orca

Add-ons and plugins for [Orca](https://github.com/stablyai/orca). This repo is its own plugin catalog (`orca-catalog.json`):

```sh
orca plugin catalog add drdla/orca-addons   # then re-run with the --approve <fingerprint> it prints
orca plugin install drdla.code-review-requests
```

Each plugin in `plugins/` has a README on installing and releasing it.
